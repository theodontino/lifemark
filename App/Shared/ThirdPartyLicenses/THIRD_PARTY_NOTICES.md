LifeRecord is an independent local development project. The following source and libraries retain their upstream licenses and copyright notices. Full license texts are in Licenses/ and are bundled with the app.

## Package dependencies

UPSTREAMS.lock.json lists observed versions and commits. Individual notices are in Licenses/Dependency-*. The resolved Swift toolchain macro packages may use Apache-2.0 with Swift Runtime Library Exception. Original source notices are preserved. This inventory is not a claim that every optional upstream feature or separately downloaded model has been independently audited.

Upstream crash reporting and automatic updater dependencies have been removed from the active app project. Local no-op telemetry compatibility types keep existing source call sites compiling; they do not implement a reporting service.
