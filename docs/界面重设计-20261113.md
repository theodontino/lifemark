# 界面重设计 · 2026-11-13

设计稿：https://claude.ai/artifact/4iDDyAFD8LYZqfk1X635Pn 。在“交互复查修复-20261113”那版代码之上改，底层存储和计时逻辑未动。

## 改了什么
- 导航改为五项：现在、时间、账本、待核对、设置。原“回顾与分析”取消，分析并入时间页（日/周/月）和账本页（明细/分析）。
- 颜色分浅色、深色两套（Theme.swift 的 lifeColor），侧边栏不再用系统蓝。
- 现在：正在计时的卡片在最上面；“切换到这一项”“同时开始”是两个按钮；类别和最近事项是可点的标签。
- 时间：带小时刻度的时间线，同时进行的事并排；周/月显示每天记录时长。
- 账本：净支出为主数字，明细按天分组，账期可前后翻页。
- 待核对：独立页面带角标；冲突并排显示并标出不同字段；读不出的记录在这里提示。
- 记一笔 / 补记窗口：输入框有边界，取消和保存并排在右下角；“值不值”只在修改已有消费时出现。
